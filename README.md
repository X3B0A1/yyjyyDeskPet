# 美洲狮来了

一只会在你电脑桌面上散步的 Q 版美洲狮桌面宠物。它在屏幕上慢慢爬行、偶尔扑向鼠标、被点到会吓一跳。支持多角色、每个角色独立调节动作参数，还能自己添加喜欢的宠物。

完全离线运行，不需要网络，不需要安装任何东西。

![美洲狮来了](0.png)

---

## 快速开始（下载即可玩）

1. 到仓库页面点击绿色 **Code** → **Download ZIP** 下载并解压；
2. 也可以直接下载打包好的程序：`dist/美洲狮来了.exe`；
3. **双击 `美洲狮来了.exe`** —— 一只美洲狮就会出现在你的桌面上。

> 如果你下载的是源码（`main.py` 等文件），运行方法见下文「源码运行」。

---

## 怎么玩

| 操作 | 效果 |
|---|---|
| 点击宠物 | 它会吓一跳（播放惊吓动画） |
| 鼠标在宠物附近停留 | 有概率扑向你，再吓一跳 |
| 按住左键拖动 | 拖到屏幕任何位置放下（先右键选「暂停」再拖更稳） |
| 右键点击 | 打开宠物菜单 |
| 托盘图标（任务栏右下角） | 同样有完整菜单 |

### 右键菜单 / 托盘菜单

- **暂停** —— 宠物完全静止，方便拖动或挂机；
- **追随鼠标** —— 开启后宠物会一路爬向你；
- **新建宠物** —— 再开一只，可同时养多只；
- **角色** —— 直接切换已有角色（勾选当前角色）；
- **角色管理** —— 添加、编辑、删除角色；
- **设置** —— 调节当前宠物的动作参数；
- **退出** —— 关闭宠物。

## 添加你自己的宠物角色

想换只别的宠物？非常自由——**任何一组图片**都可以当角色。

1. 右键宠物 → **角色管理** → **添加宠物**；
2. 填写宠物名字；
3. 选择**爬行图片**（走路/爬行的几帧图）和**惊吓图片**（被吓到的几帧图）；
   - 可以一次多选（按住 `Ctrl` 或 `Shift`），也可以分多次追加；
   - 图片支持 png / jpg / bmp / gif / webp；
   - 帧图按文件名数字顺序播放，例如 `crawl_1.png`、`crawl_2.png`……
4. 选择它的**正面朝向**（朝左还是朝右），保存后自动切换过去。

之后就能在右键菜单 → **角色** 里随时切换。

> **小提示**：爬行图、惊吓图不一定要一样大。程序会自动把所有帧等比缩放到相同大小并对齐，所以混用不同尺寸的图也不会忽大忽小。

### 手动放图片（可选）

不想用「角色管理」界面的话，也可以直接放文件夹：

```
characters\
└── 我的宠物\           ← 文件夹名 = 角色名
    ├── crawl_1.png     ← 爬行帧（crawl_开头的数字）
    ├── crawl_2.png
    ├── scare_1.png     ← 惊吓帧（scare_开头的数字）
    └── config.json     ← 可选，角色参数
```

重启后新角色就会出现在菜单里。

## 设置项说明（设置窗口里可调）

| 参数 | 含义 |
|---|---|
| 爬行速度 | 爬得多快（像素/秒） |
| 爬行帧速率 | 走路动画每秒播放几帧 |
| 摇摆幅度 / 频率 | 走路时摇摆抖动的幅度和快慢 |
| 宠物大小 | 显示尺寸百分比 |
| 鼠标感应半径 | 鼠标离它多近会被发现 |
| 停留触发时间 | 鼠标停在附近多久会扑过来 |
| 扑向概率 | 触发扑向动作的概率 |
| 扑向速度 | 扑过来的速度 |
| 惊吓时长 | 吓一跳持续多久 |
| 帧交替间隔 | 惊吓动画两帧切换的快慢 |
| 惊吓抖动幅度 | 被吓到时抖得多厉害 |

每个角色独立保存自己的参数，改完只影响当前宠物。

## 源码运行

想从源码跑（比如自己改代码）：

1. 安装 [Python 3.10+](https://www.python.org/downloads/)；
2. 安装依赖：
   ```
   pip install pillow pystray numpy
   ```
3. 运行：
   ```
   python main.py
   ```

> 注意：源码运行时，`characters\` 文件夹会在首次启动自动创建，并从内置图片生成默认角色「美洲狮」。

## 常见问题

**双击 exe 没反应？**
- 检查杀毒软件是否拦截（首次运行可以右键 → 以管理员身份运行试试）；
- 试试点右下角托盘图标，看看宠物是否躲在屏幕边角。

**想在多台电脑玩？** 直接把 `dist/美洲狮来了.exe` 拷过去就能用，不用装任何东西。

**系统要求：** Windows 10 / 11（64 位）。
